Privacy Policy — "hermes"

Last updated: 19 October 2026

Who uses this app

"hermes" is a private personal-assistant application. It is operated by and used only by its owner, Jahonbek Sayfiddinov (jahonbek1798@gmail.com). It is not offered to the public and no other person's data is processed.

What Google data it accesses

  • Gmail — to read, summarise, draft and send the owner's emails when the owner asks.
  • Google Calendar — to list and create the owner's events.
  • Google Drive, Docs and Sheets — to find, read and create the owner's files.
  • Google Contacts (read-only) — to look up an email address by name.

How the data is used

Data is used only to carry out tasks the owner explicitly requests. To generate a reply, the relevant text may be sent to the AI model provider used by the assistant (via OpenRouter); it is not used to train models by the app and is not used for advertising.

Storage and sharing

The access token and working files are stored only on the owner's own computer. Google user data is not sold, shared with, or transferred to any other party, except the AI processing described above.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
